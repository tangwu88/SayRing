## 本轮不可冒充已通过的项目

- 主机测试只使用合成数据；不是对真实家人发邀请或改授权的验收。
- 模拟器读取成功只证明该账号/该日期的返回链路，不代表所有用户或所有指标均有健康数据。
- 真实波形点仅保留真实数据与元信息；未绘制原生波形图，不生成模拟心电波形。
- 没有连接实际手机/手表、改服务器、支付、市场上传、强行合并 Git 或清空登录信息。
- 未执行原 Flutter 工程的跨平台发布门禁，本轮原生源码未提交/推送。

## 下一批建议顺序

1. 关爱双账号写入联调与服务端并发授权契约，再补原生趋势/真实波形查看。
2. 注册/密码找回、资料编辑、关于我们/联系与原生在线升级。
3. 厂商 SDK 到位后接入手表主链路，并用真实原生鸿蒙手机全面验收。
4. 正式签名与市场材料就绪后，才产出可分发/可提交的发布版本。
