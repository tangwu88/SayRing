### 自动化范围

- 鸿蒙主机测试共 **53 项**，分别在 `TZ=UTC`、`TZ=Asia/Shanghai` 下 **53/53 通过**。不是旧 Flutter 的 53 项，也不是原生 UI 自动化。
- 测试直接覆盖生产 Contracts 与 AccountClient；注入合成凭证、内存存储和可控网络，不使用用户账号/密码/个人资料夹具。
- NativeHttpTransport、Asset Store 与 ArkUI 的系统调用仅经原生编译及有限模拟器运行检查；主机替身测试不能代替系统 API 和交互验收。
- 最终 Debug 与 Release 各自构建结果见后续安装记录；Release 元数据必须为 `debug=false` / `buildMode=release`，但签名缺失仍阻止分发。

- 改登录/刷新先跑换账号、退出、晚到 401、并发弱网测试，不能只测单次成功。
