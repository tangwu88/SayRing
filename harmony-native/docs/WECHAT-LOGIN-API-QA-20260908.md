# App 微信登录接口联调记录（2026-09-08）

## 结论

Harmony 微信授权登录已在华为 nova 14 真机闭环通过。

客户端使用微信官方 SDK 拉起授权页，严格校验回调中的一次性 `code`、`state` 和超时状态，再将 `code` 提交给 `POST /api/v1/site/app-wechat-login`。服务端返回有效登录会话后，App 正常进入健康首页。

## 接口合约

Apifox 页面：`https://s.apifox.cn/860ee0ab-38c8-44b8-baa5-82ce567e7994/511582553e0`

- 方法：`POST`
- 地址：`/api/v1/site/app-wechat-login`
- 类型：`multipart/form-data`
- 身份凭证：微信官方 SDK 返回的一次性 `code`
- 兼容字段：`unionid`、`openid`、`sex`、`nickname`、`headimgurl`；客户端没有可信值时传空，不伪造资料
- 成功响应：`access_token`、`refresh_token`、`expiration_time`、`member`

AppSecret 只允许保存在服务端，未写入客户端源码、配置、测试或安装包。

## 本轮问题与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 微信显示 `empty scopes` | 微信开放平台 Harmony 应用配置未完成 | 产品方更新开放平台配置后，授权页已正常显示昵称和头像授权范围 |
| 授权后提示“微信未返回登录信息” | Harmony SDK 回调有有效 `code`，但不保证返回 `openId`；客户端错误地把 `openId` 当作必填 | 改为以官方一次性 `code` 登录，`openId` 仅作为可选兼容字段 |
| 微信资料包含控制字符时页面显示异常 | 服务端资料字段可能包含不可见控制字符 | 昵称展示与编辑入口增加控制字符过滤和安全回退 |

## 真机验收结果

测试设备：华为 nova 14；应用：`cc.saidian.app.hm` 0.1.4（9）。

1. 勾选隐私协议后点击微信登录，可正常拉起微信授权页。
2. 点击允许后，SDK 返回有效一次性 code；App 调用登录接口，HTTP 200，并进入健康首页。
3. 微信新账号建立独立会员会话，本轮测试会员 ID 为 113。
4. 补齐昵称、性别、生日、身高和体重后保存成功；退出页面再进入，资料仍正确显示。
5. App 退到后台再打开，登录状态保留。
6. 强制结束进程后重新启动，仍直接进入健康首页，登录状态保留。
7. 取消、过期、state 不匹配、空 code、账号切换失败等安全路径由自动化测试覆盖。

## 服务端仍需保持的安全要求

1. 服务端使用安全保存的 AppID/AppSecret 向微信兑换并校验一次性 code。
2. code 只能消费一次；对重放、过期、AppID 不匹配返回明确且安全的业务错误。
3. OpenID/UnionID 只能来自微信服务端响应，不能信任客户端自报值。
4. 同一微信用户重复登录不得创建重复账号。
5. 异常响应不得返回服务器目录、源码文件、行号或调用栈。
