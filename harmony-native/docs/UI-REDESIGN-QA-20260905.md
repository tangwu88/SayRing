# 鸿蒙版界面重设计与适配验收（2026-09-05）

## 本轮目标

以苹果版和已确认的赛电首页为信息与品牌基准，重新梳理鸿蒙版界面。

不复制 iOS 控件，不改动真实业务数据，重点解决层级混乱、操作粗糙、图片裁切、触控范围和大字适配问题。

## 设计原则

- 品牌：保留赛电红，增加暖白背景、浅红、浅金、浅蓝和浅绿状态面。
- 层级：一个页面只保留一组主操作，主按钮使用赛电红，次操作使用柔和底色或描边。
- 可读：标题、说明、状态和操作文案明确分层，不再使用文本箭头、文本勾号和其他假图标。
- 触控：常用操作保持不小于 48 vp 的触控高度，组合卡片允许随系统大字向下增长。
- 真实：无真实数据时继续显示“暂无记录”或“设备不支持”，不为了视觉效果生成模拟健康值。

## 已完成页面

### 健康首页

- 重做用户问候、通知入口和 AI 健康管家卡片的主次关系。
- 远程关爱、健康百科、健康预警和赛电商城改为两列大触控卡片，使用鸿蒙系统 Symbol 图标。
- 健康项目卡片增加语义图标、真实状态和明确的“查看”入口。
- 连接状态、最近同步时间和设备不支持状态分开显示。

### 设备页

- 当前设备、厂商、电量、MAC、型号、固件和同步时间收拢到设备摘要卡。
- “同步近三天”作为主操作；同步时间、查找手表、读取设置和读取表盘归入快捷控制区。
- 断开设备移至页面底部并使用警示描边，降低误触。
- 扫描列表保留 Vep/Yuc 、真实 MAC/设备标识和信号强度，卡片层级与已连接页一致。

### 商城与订单

- 商城头图和内容配图增加统一圆角，商品缩略图改为完整显示，不再强行裁剪主体。
- 分类、商品、价格、库存和查看操作的信息密度已统一。
- 支付方式使用完整的“已选”状态和边框，不再使用文本勾号充当控件。

### 我的与二级页

- 个人信息、设备/记录/关爱摘要、订单和常用服务按任务分组。
- 个人资料、AI 提问和消息推送改为“标题＋用途＋操作”列表，降低识别成本。
- 所有二级页统一顶部标题、返回触控区、页边距、状态提示和底部安全留白。
- 底部三个主导航改为系统图标＋文字，当前页使用浅红选中面。

## 自动化门禁

- 增加暖色品牌 token、卡片边界、矩形操作面和商品图片比例的静态回归。
- 增加“不使用文本字形冒充图标”和“显式按钮不低于 48 vp”的防回归检查。
- 系统字号继续跟随鸿蒙设置，最大支持 2 倍字号；卡片尽量使用最小高度而非固定高度。
- 鸿蒙测试在 `UTC` 与 `Asia/Shanghai` 两个时区分别执行，均为 126/126 通过。
- Flutter `analyze` 为 0 问题，完整测试 382/382 通过，确认鸿蒙界面改造未影响共享业务逻辑。
- 鸿蒙 Debug HAP 与 Release APP 均构建成功；厂商 HAR 的资源重名、未混淆和既有数据存储告警保持登记，不属于本轮新增问题。

## 真机验收

- 设备：华为 nova 14，HarmonyOS 6.1，API 24。
- 手表：W9S；验证连接摘要、36% 真实电量、今日数据同步完成和页面间切换。
- 页面：健康首页、健康卡片列表、已连接设备、扫描列表、商城、商品详情和“我的”已截图逐页检查。
- 结果：未发现应用内容溢出、图片强制裁切、主导航遮挡或二级页返回失效。
- 最终 Debug 包已覆盖安装到真机并保留应用数据；重启后 W9S 自动恢复连接，设备名称和同步状态显示正常。

真机截图包含用户昵称和设备标识，只保存在本机临时 QA 目录，不提交 Git，不进入对外交付包。

## 边界

本轮是界面与交互整改，不伪造服务端能力。Yuc 鸿蒙 SDK、商城原生下单、真实支付签名、生产推送和 AppGallery 生产更新仍以原有阻断清单为准。
