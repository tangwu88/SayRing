## 防回归要点

- 无数据卡片只保留一个主空态，辅助行说明下一步操作。
- 登录方式可增加，但不得恢复未登录浏览健康首页。
- 应用密钥只允许在服务端密钥管理中保存，不得写入客户端、Git、日志或交付文档。
- 全新工程构建前必须按锁文件完成 `ohpm install --all`。缺少微信 SDK 时编译器会同时报模块不存在和回调类型不明；先恢复依赖再判断源码类型问题，不要为了绕过缺包而放宽类型。
