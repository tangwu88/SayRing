# 鸿蒙设备页与 Android 功能对齐记录（2026-09-09）

## 目标

以 Android `DeviceFeature` 为基准补齐鸿蒙设备页，并通过手表能力标志决定入口是否显示。设置类操作必须调用厂商 SDK，并在写入后重新读取确认，不使用本地假成功。

## 本轮实现

| Android 功能 | 鸿蒙实现 | 数据来源与边界 |
| --- | --- | --- |
| 表盘中心 | 已保留 | 读取、切换手表内实际表盘 |
| 照片表盘 | 已新增 | 选择本机图片，读取手表尺寸后通过 Vep 照片表盘通道传输并展示进度 |
| 相机遥控 | 已新增遥控协议页 | 可开启/关闭手表相机遥控并接收手表拍照事件；鸿蒙 CameraKit 取景及相册落盘尚未实现 |
| 电话 | 已新增 | 读取手机蓝牙通话状态，并调用手表蓝牙通话连接能力 |
| 联系人 / SOS | 已新增 | 读取、添加、删除联系人及设置唯一 SOS 联系人；每次写入后回读确认 |
| 消息通知 | 已新增 | 仅显示手表实际支持的通知类型，切换后回读确认 |
| 闹钟 | 已保留 | 原有手表闹钟读取、添加、编辑、删除 |
| 天气 | 已新增 | 读取并保存手表天气开关及摄氏/华氏单位，写后回读 |
| 世界时钟 | 已新增 | 读取、添加、删除城市时钟，写后回读 |
| 健康提醒 | 已新增 | 读取并配置手表实际支持的久坐等提醒 |
| 健康监测 | 已新增 | 读取可配置的自动监测项目，支持开关及间隔设置，写后回读 |
| 健康辅助评估 | 已新增 | 读取并配置手表实际支持的辅助评估项目，写后回读 |
| 屏幕显示 | 已新增 | 配置亮屏时长与抬腕亮屏；当前 Vep 鸿蒙 SDK 未提供连续亮度等级写入接口 |
| 查找设备、同步时间、设备信息、设备设置、健康同步 | 已保留 | 使用现有真实 SDK 通道 |

## 兼容与稳定性处理

- W9/W9S 部分旧固件未设置 `b3AutoMeasure` 汇总标志，但会报告心率、血压、血氧、体温或 HRV 能力。本轮改为保留“健康监测”入口，再由 `AutoMeasureService` 返回实际可配置项目。
- Yucheng W8 SDK 的厂商自动重连缓存不区分 App 内部的 Vep/Yuc 路由，可能抢占 W9/W9S 蓝牙链路。本轮关闭 SDK 自行重连，改由 App 按账号、绑定设备和供应商显式恢复连接。
- W8 当前公开封装仍只暴露连接、电量、健康同步、测量、运动、闹钟、查找与时间同步等已验证事务。Vep 专用高级设置不会伪装为 W8 可用；需拿到 W8 对应设置协议后逐项接入。

## 验证结果

- Node 契约测试：441 项通过，0 失败。
- Harmony Debug 构建：成功；仅保留依赖 SDK 的既有警告。
- 鸿蒙手机 `4UQGL26514000177`：设备页启动正常，能搜索到 `SD-watch-W9S`、`SD-Watch-W9Pro` 和 `W8-ultra 3B0F`。
- `SD-watch-W9S`：连接成功，设备名称、电量、同步、表盘与能力入口正常展示；联系人页面已从手表读取为空列表，未写入测试联系人。
- `SD-watch-W9S`：消息通知、天气、世界时钟、辅助评估和屏幕显示页面均能读取并展示手表返回的设置；连续进入和退出多个设置页后等待 15 秒，设备仍保持已连接。
- `SD-watch-W9S`：健康监测入口已按分项健康能力展示，但当前鸿蒙 Vep SDK 的 `AutoMeasureService.readConfig()` 返回空列表。Android 使用的旧版 `CustomSettingData` 分项接口在当前鸿蒙 SDK 中未公开，因此页面明确提示手表未返回可配置项目，不伪造本地开关。

## 尚需实表写入验收

- 联系人/SOS、提醒、监测、辅助评估、天气、世界时钟和屏幕设置会改变手表配置，本轮只做了读取及代码级写后回读验证，批量写入验收需使用专门测试表。
- 照片表盘传输需要一张允许写入测试表的图片。
- 相机遥控要达到 Android 的取景、拍照并保存到系统相册，还需增加 CameraKit 页面与媒体写入权限的按需申请。
- W8 高级设置需要厂商提供对应鸿蒙 API 或协议后才能与 Android 完全对齐。
- W9S 旧固件的自动健康监测开关需要 Vep 厂商补充鸿蒙版 `CustomSettingData` 等价 API，或升级固件使 `AutoMeasureService` 返回配置项，才能完成实表读写对齐。
