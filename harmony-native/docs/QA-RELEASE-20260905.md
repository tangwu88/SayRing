## 兼容与隐私检查

- PaymentKit 只在确认系统能力且用户主动支付后加载，缺少支付 HSP 的设备冷启动不再崩溃。
- 推送路由不接受任意 URL；系统健康通知不携带健康值。
- AppKey 可公开集成，Master Secret、Server key、支付密钥和签名密码不得进入源码或日志。
- 合并 HAP 权限包含 INTERNET、GET_WIFI_INFO、GET_NETWORK_INFO、APP_TRACKING_CONSENT；正式版隐私说明和市场清单必须与实际 SDK 权限一致。
- 归档脚本检查 HAP/APP 结构、版本、debug/buildMode、合并权限、源码白名单和 SHA-256。

## 不能据此声明通过的项目

- 模拟器页面与合成测试不等于真实鸿蒙手机推送送达、第三方 App 拉起或支付到账。
- 订单只读成功不等于 `/api/v1/pay` 已支持 Harmony 参数。
- Release 编译成功不等于已签名、可安装、可升级或可提交应用市场。
- 本轮没有手表 SDK、蓝牙、健康同步、测量、表盘或运动的原生鸿蒙真机验收。
