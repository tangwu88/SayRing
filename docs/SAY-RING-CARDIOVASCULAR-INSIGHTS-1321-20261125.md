# Say Ring 1321 心血管趋势

2026-11-25，以 `codex/say-ring-connected-experience-20261123` 的 `14724c6` 为基线。华为 PPA-LX3 开始验证时安装的是 1.0.15（1320）。

## 页面与数据

- 健康首页移除顶部入口。iOS 和 Android 从「健康 → 健康数据 → 全部数据」进入「全部健康数据」，最后一项为「心血管趋势」。
- 趋势页默认近 7 天，可看近 30 天并选择结束日期。先看选定来源最近一次收缩压、舒张压和测量时间，再看趋势解读、依据和每日平均曲线。当前周期无血压而上期有记录时会正确显示空态。切换来源、日期或账号后会重新选择相应记录。
- 血压日均值按有记录的日子等权比较。上臂参考值和各穿戴设备独立。心率按日内真实采样求平均，睡眠按 SDK 日期取有效时长，步数区分区间值和累计快照。穿戴血压只匹配同设备同期指标。上臂参考值选有共同日期的设备，每项指标在两期都使用同一设备。
- 解读给出高低压变化、同日血压与穿戴指标数值，以及有充分匹配日期时的两期变化。两期对比各需至少 3 个有效日。同日分析使用两项记录共同出现的日期，在「查看依据」可核对来源、记录日及相应数值。缺少血压时能查看已有的穿戴数据；一个可选指标读取失败时其余结果仍可展示。
- 本包使用 AI 起草并核对的中英文通用文案。手机用本机统计填充占位符。本轮没有取用会员数据向模型发起推理。发行编辑工具 `tool/draft_cardiovascular_copy.py` 支持使用第一方已配置的模型起草新文案，固定输入为双语文案目录，草稿需另行校对。当前通用文案由本轮开发 AI 辅助起草；线上配置模型的编辑账号联调待凭据。
- 日期、血压读数与已有加密数据、账号隔离、U19 型号及云端读回条件沿用原有规则。此次新增过滤明确标为无效的穿戴血压记录。不触发测量、校准、固件操作或健康数据写回。

## 回归与测试包

- 新入口的旧版回归先出现预期失败。窄屏两倍字号用例首次滚动定位到了屏幕外的可访问文本，改为滚动至可点击目标并等待布局完成。测试覆盖 iOS／Android、中／英文、打开与保存上臂参考值、单点与缺日断线。
- 针对心血管的 14 项自动检查通过，覆盖两期有效天数、同日匹配、设备来源隔离、睡眠跨午夜、缺期、重复步数快照、无血压及可选指标读取失败等情况。最终完整 Flutter 测试在 UTC 和 Asia/Shanghai 各通过 2,487 项。Dart 格式与静态分析通过。中英文文案字段校验通过，也验证了缺语言、占位符不符或版本错误会被拒绝。
- Android 模拟器使用真实 Flutter 页面和内存测试数据，从首页进入完整指标目录，确认「心血管趋势」位于「睡眠」下方。点进后核对了 7／30 天、同日血压和心率、展开依据及来源。两期各有三天的截图复核还覆盖了缩短后的日期区间，以及两项统计采用相同记录日时只显示一次收缩压变化。测试使用一次性只读模拟器，记录仅存于内存。
- iOS Debug 与 Profile、Android Debug 与 QA Release 构建通过。真机测试 IPA 已核验签名、1.0.15（1321）以及 `cn.saydian.ring`。华为覆盖包与手机原安装包签名一致，已验证归档对齐和构建号；三个交付安装包均核对了随包文案与仓库版本一致。
- 华为设备已识别。首次安装等待机主确认超时，最终签名包再次进入华为系统「风险提示」。当前真机读回仍为 1320，覆盖与新页面验收尚待确认。iPhone 的本轮验收证据为构建与自动界面测试。
