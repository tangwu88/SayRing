## 已实施（持续执行至 2026-09-07）

- 登录页“忘记密码”进入已有真实短信重置表单；密码与验证码离开即清理。复用原接口，不把说明页当成功流程。
- 表盘中心改为独立页，只显示 SDK 已安装列表、当前项与确实可用的切换/回读/恢复操作；无真实图片显示“预览暂不可用”。设置独立只读页保留真实读取/同步时间，不增加没有写入桥接的按钮。
- 关爱指标补与 iOS 相同的当日最近、平均、最高、最低、记录数；血压只聚合完整同条双值。心电/身体/血液成分不生成无意义平均。成员记录新增详情，心电可翻阅完整采样末段。
- 页面宽度与系统字号共同决定单列布局，文字按钮最低 48vp 并随字号增高；登录短信行、健康快捷入口/统计/指标卡、设备动作适配窄屏。输入法压缩内容区。个人资料对照本轮 iOS 当前源码渲染改为独立输入框并补读取失败重试。
- 移除 singleton previousScreen 冗余状态，复用现有内页父路由避免五层返回跳错；修复同页重入形成自己父页的问题。波形宽度按真实容器计算，不再固定 280vp 拉伸。
- 接入并行任务已实现的前台健康上传重试、支付能力检查及通知到达 revision。到达仅回读服务端消息/关爱列表，不自动跳页、不信任推送健康值；白名单 messages 点击进入消息中心。
