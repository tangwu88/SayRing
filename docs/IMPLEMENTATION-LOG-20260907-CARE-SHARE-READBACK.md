## 实际修改

- `api_client.dart`：复用原关爱请求的账号归属检查，增加同样受保护的 JSON POST。保存先复制完整设置快照；POST 成功后仅向原 `type`、原 `to_member_id` 回读，集合完全一致才返回。没有改共享方向、枚举、全局重试或其他 API。
- 设置读取支持原 JSON 字符串列表和直接数组。保留未知非空字符串权限键；缺字段、非法 JSON、非列表或列表中的非法值均明确失败，不默默解释为“未授权全部项目”。显式 `[]` / `"[]"` 仍是有效空集合。
- POST 后回读失败或不一致返回“保存未确认，请重新读取后重试”，不承诺服务器没有写入。账号变化错误仍保持独立，不用新账号继续旧操作或刷新旧请求。
- `app_controller.dart`：共享读/写使用现有会话代次与账号切换门禁；保存去重和 busy 释放只对原会话生效。实际退出后，旧成功、服务端错误、断网错误都不得清除新会话 busy、覆盖错误或触发通知。
- `prototype_pages.dart`：保存中禁用分组、单项、重复保存和重新读取；失败保留草稿并禁止盲目再次保存，正常“重新读取共享设置”会恢复真实回读值。账号变化时隐藏旧权限项，不继续旧页面操作、不弹旧成功或错误提示。
- 文案改为“仅共享已开启的项目，更改后请保存”，删除“关闭后保存即可撤销”和“当前不会更改任何授权项目”的过度承诺。
- `test/care_share_settings_test.dart`：44 项执行真实 API / Controller / 页面测试；请求使用合成账号与 `example.invalid`，无真实授权写入。既有 `api_client_test.dart` 只调整一条保存夹具：增加精确 GET 回读与次数断言，权限键改用真实 `HRV` / `heartReat`。
