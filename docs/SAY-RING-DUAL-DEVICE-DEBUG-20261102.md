# 苹果与安卓普通客户端双真机调试

本轮按用户要求在 USB 连接的 XR 和华为上开启调试。启动前从 origin 核对开发分支，应用源代码为 e83eb179db112732c442b99127446f91c401e2bc。两端使用 cn.saydian.ring 和普通 lib/main.dart；不切换账号、不解绑、不给戒指发送清空或恢复出厂指令。带调试能力的安装包、账号数据、调试会话地址不进入 Git。

- iPhone XR：使用最近验证过的、包含本次源代码的开发签名 Debug 1.0.10（1226），校对原生程序与 Dart 内核指纹。先做私有备份，原位安装后、启动前比对 56 个受保护的数据文件，逐个 SHA-256 相同。从正常入口启动 App，Flutter 报告启动完成，主程序可运行并且未暂停，DevTools 返回 HTTP 200；核对手机实际显示健康首页。
- 华为 PPA-LX3（Android 10）：USB 授权可用。原正式版为 1.0.10（1228）。使用相同版本号、产品配置与原证书构建正常入口 Debug；已核对包名和签名。使用 adb install -r 保留数据发起一次覆盖，停在手机系统的“风险提示 → 继续安装”。此时仅为待确认，不能把电脑已识别手机、已签名或安装进程等待写成已附加安卓 Flutter。
- 华为确认后：手机用户点击“继续安装”，旧版安卓不支持增量安装，ADB 自动改为流式覆盖，返回 Success。装后私有核对 APK SHA-256 与候选一致，原应用 UID 及首次安装时间保持不变，没有卸载、清数据或换号。
- 安卓首次附加把电脑转发端口当成手机端口，造成二次转发而失败；保持 App 进程不动，改用手机实际 VM 服务地址让 Flutter 自行转发，随后成功。手机普通健康首页在前台，Flutter Inspector 可用，主程序可运行且未暂停。最终在同一时段复核：XR 和华为的 VM 均为 runnable / Resume，两个本机 DevTools 页面分别返回 HTTP 200，会话保留。
- 合规及证据边界：本轮没有修改产品源码、跑蓝牙或同步专项、上传安装包或提交审核；已有安装验证不等于锁屏恢复或睡眠读数验收。私有设备容器、签名配置和带会话令牌的 DevTools URL 不进仓库。
