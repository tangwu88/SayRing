# 2026-09-11 Android 登录后双型号设备与新域名联合复验

## 范围与成功标准

- 基线：国际版仓库 `main`，开始时 `HEAD == origin/main == 6217b16bdeff0e2a69e481e1682ce2ef1182535e`，工作树干净、ahead/behind 为 `0/0`。
- 真机：已登录的华为 Android 10 手机，覆盖保留现有账号、本机记录和设备信息；未重装、未清数据、未退出账号。
- 目标：优先查找原保存手表；若目标不出现，按用户本轮明确授权连接扫描列表中信号最近的其他手表。验证连接、同步、按型号展示能力、主要登录后页面、新域名请求和进程稳定性。
- 安全边界：不修改联系人、表盘、闹钟、提醒、监测、屏幕、健康设置或账号资料；不执行支付、下单、退款、发货、删除账号、退出登录和 OTA；原始日志、设备标识、账号信息及健康数值不提交 Git。

## 修改范围

## 目标未出现与 ADB 恢复记录

1. 精确保存目标在连续扫描中未出现；系统蓝牙状态同时显示其经典通话链路仍连接。BLE 外设在这种状态下可能不继续广播，因此本轮没有把“未出现”误报为 App 筛选错误，也没有重置手表或系统配对。
2. 用户明确允许目标缺失时连接信号最近的另一块手表。扫描列表按实时信号动态变化；自动点击期间列表曾重排，最终 SDK 连接到 W8Pro。该结果保留为测试工具与动态列表的竞态，不据此判断用户手动点击会选错。
3. USB ADB 在扫描期间多次转为 `offline`，并导致一次 UI XML 截断。曾尝试临时无线 ADB，但局域网路径保持离线，随即关闭并移除。执行 ADB 服务/USB 模式恢复后，连续 10 次一秒间隔状态检查均为 `device`。
4. 保留两次测试脚本错误：一次 PowerShell 使用只读 `$PID` 名称发生冲突；两次长轮询因调用超过工具让出时间且未保留会话标识而丢失输出。均只影响测试采集，不是 App 故障；后续使用任务专用变量并拆短采样。

## 新域名与服务端联合核验

- 源码固定国际环境为 `https://app.saydian.cn` 与 `/global/api/saydian-app/v2`；国际客户端负责将现有 `/api/...` 契约映射到隔离 `/global/...`，媒体和文章也有国际环境归一化入口。
- 最终当前进程结构化日志快照：68 条第一方事件全部为 `app.saydian.cn`，其中 28 个 HTTP 200、6 个 HTTP 201 响应，发送/响应各记一条；18 条 `www.vphband.com` 事件为 9 次官方表盘请求及其 HTTP 200 响应。允许清单外主机为 0，旧赛电第一方域名文本命中为 0。
- 以上是 App 自有结构化日志和当前进程滚动缓冲区，不是系统级全流量抓包。官方表盘服务是已区分的第三方能力，不应误报为第一方回退。
- 手动“检查更新”期间曾记录国际更新清单 404；本地路径哈希对应 `/global/api/saydian-app/v2/support/app-update`。服务端联合任务确认国内 `/api/...` 有旧国内 QA 清单，但国际 `/global/...` 尚未发布独立签名安装包，因此 404 是明确的未发布状态，不能回退国内清单或伪造成功。
- 国内基础客户端仍保留旧媒体域名兼容替换代码；国际客户端对本轮相关媒体/文章/URI 路径另行收口，实际真机结构化请求没有旧域名。该结论限于当前覆盖路径。
