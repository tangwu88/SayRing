# Say Ring 1323 四项功能续验

2026-11-25。App 从 `7738aa4` 接续。后台候选从 `75f00a0` 合入已拉取的中国站主线 `62bf80e`。本轮补齐上一轮检查发现的用户流程。

## 行为

- 心血管趋势可以在「查看依据 → 逐条查看血压记录」修改和删除手填的上臂血压。原账号的加密存储格式仍可读取。修改日期后可看到对应时段。穿戴读数继续沿用原健康记录。
- 线上模型根据相对变化、同日配对和记录天数，选择最值得显示的比较和顺序。App 用实际统计渲染模型选中的项目。响应含未提供的指标、没有依据的比较类型或其他文字时拒绝显示。记录不足时先提示继续记录。查看依据和本机曲线在网关异常时仍可使用。
- 分享预览内可重新选择记录日期。同日多条记录可选，空日期会清掉旧预览。日／周／月睡眠报告都可选实际汇总，健康记录保留同来源和读取权限，亲友只读健康数据不出现二次分享。我的分享可查看已过期链接的回应和更早记录。我的这一周优先比较同一设备的睡眠或两周同一时间段的运动记录，资料不足时保留一条真实回顾。
- 远程爱邀请待接续状态在本机加密保存，到期、已处理或账号不匹配时失效。邀请读取遇网络或服务错误可重试。散步约定使用后台确认的当天有效穿戴活动，也可手工打卡。H5 提供直接打开、复制邀请码和下载回退。iOS 签名加入 `links.saydian.cn`，待此域名的匹配证书和关联文件完成才在 H5 启用跨域打开。
- iOS QRing 的升级页显示原厂 SDK 传输进度，以及重启、重连、版本核对阶段。只有原设备读回目标版本才显示成功。当前未获得准确型号的原厂升级包和恢复说明。Android QRing、CoolWear、U19 适配及真实断连恢复仍待验。轻振未取得任何型号的双端业务验收。
