# 支付与 W9S 真机验证记录（2026-08-31）

## 1. 验证范围

- 检查订单支付页到服务端下单接口、原生微信/支付宝 SDK、回调和订单状态刷新的完整客户端链路。
- 真机只验证支付参数解析、原生通道保护及安全失败，不确认付款、不产生扣款。
- 连接 iPhone 15 Pro Max 与 W9S，执行不改变用户资料和表盘的安全功能回归。

## 2. 客户端已完成

- 支付接口继续只提交订单标识，由服务端决定金额并生成签名参数；客户端不生成、不补写、不修改签名。
- 微信支付兼容多层 `config/pay/params/data/result` 包装和常见字段别名，缺少任一必填字段时拒绝唤起 SDK。
- 支付宝兼容直接字符串及 `orderInfo/orderString/payInfo` 等服务端返回形态，空参数时拒绝唤起 SDK。
- iOS 已接入微信和支付宝官方原生 SDK、URL 回调、Scene 回调及结果查询通道。
- Release 门禁会检查微信 AppID、Universal Link、支付宝回跳 Scheme；占位值不能生成生产包。
- API 层保留支付宝可能直接放在 `data` 中的签名字符串，不再因只接受 Map 而丢失。
- 支付结果页仍通过服务端订单查询确认最终状态，不以客户端回调单独认定已付款。

## 4. W9S 真机结果

- iPhone 扫描到 W9S，并由 Veepoo 路由识别为 `Vep`。
- 能力读取成功；只测试设备实际声明支持的项目，不伪造血糖等未声明能力。
- 电量读取为 `98/100`，状态正常。
- 心电、心率、血氧、血压、体温、身体成分的手动测量均完成启动和停止，过程中没有设备断连。
- 历史同步正常结束，最终复测取得 1 条记录。
- 主动断连后重新连接同一 W9S 成功。
- 未执行表盘覆盖、OTA、恢复出厂、联系人删除或健康数据清空。

## 5. 服务器与发布阻断

- 用户现场截图显示微信和支付宝订单均未返回 APP 支付参数；客户端兼容已补齐，但服务器是否已配置商户、证书、签名及 APP 支付产品仍需服务端核实。
- 需确保 `POST /api/v1/pay` 对微信返回完整的 AppID、商户号、预支付单号、随机串、时间戳和签名；支付宝返回完整的服务端签名订单字符串。
- 支付异步通知必须幂等处理，订单最终状态以服务端通知或主动查询为准。
- 当前 iPhone 无可用外网路由，无法在真机上复核生产接口、微信/支付宝 App 唤起以及取消后的未支付状态。
- iOS 生产签名还需真实微信 AppID、Universal Link、Associated Domains 能力和支付宝回跳 Scheme；这些值只能由受保护构建配置注入，禁止提交 Git。

## 6. 上线前剩余验收

1. 恢复 iPhone 正常联网，确认支付接口只记录字段名称和类型，不记录签名内容。
2. 分别创建一笔最低金额测试订单，确认微信、支付宝能够打开对应 App 后立即取消。
3. 取消后刷新订单，必须仍为未支付；客户端回调不得改变服务端订单状态。
4. 在支付沙箱或商户测试环境完成成功、取消、失败、重复通知、延迟通知和订单查询回补测试。
5. 使用生产签名配置构建 iOS 包，复核 Universal Link、回跳 Scheme 和支付结果冷启动恢复。

在上述外部条件完成前，支付状态只能标记为“客户端已就绪、生产端到端验收受阻”，不能标记为正式上线通过。
