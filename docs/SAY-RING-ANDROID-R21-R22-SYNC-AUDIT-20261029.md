## 已确认的代码路径

- R1/R2 名称前缀优先路由到 Android QRing 桥，包含 R21/R22，并非遗漏型号。
- `QRingBridge.capabilities()` 的 `supportsHistorySync` 使用 Java Boolean，其值为 `!factoryInitializationPending()`；不同于 10 月 22 日已修复的 iOS NSNumber 数字装箱问题，不应照搬旧 iOS 修复到安卓。
- `factoryInitializationPending()` 检查精确当前所有者/环境和设备的持久化初始化回执：0 为没有初始化意图，7 为重置确认及初始化验证均完成，其他非零状态关闭历史同步。状态位 1 表示已持久化重置意图，2 为有效重置 ACK，4 为目标设置写入后真实读回验证。不能把发出请求当成收到 ACK，也不能通过清除记录、强制 true 或重发重置绕过保护。
- 原生历史读取与运动历史入口也有 `INITIALIZATION_PENDING` 拦截。Dart 严格解析 Boolean，并在设备页将 `supportsHistorySync == false` 统一显示为“此戒指历史同步暂未开放”。该文案不能区分临时初始化待确认与型号能力缺口，容易误导；本轮不在缺少原手机证据时放宽门禁。
- 现有同目标重连可继续资料/目标设置初始化，不会重复首次重置；若原重置 ACK 本身未确认，仅重新连接不能伪造成功回执。缺少原 R21 手机的回执，无法确定具体缺失的状态位或触发原因。
