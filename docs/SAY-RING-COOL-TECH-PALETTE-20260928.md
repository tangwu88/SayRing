# 2026-09-28 Say Ring 冷色科技年轻化调整

## 修改原因

上一轮浅色年轻化方案在首页和个人页使用了较多粉色、粉橙色表面，实际真机观感偏粉嫩，与年轻智能戒指产品需要的科技感不一致。本轮按产品反馈重新收拢色彩：以冷白、科技蓝、青色、靛蓝和紫色作为主视觉，品牌红只保留在关键操作、头像和底部当前选中项。

## 修改范围与设计边界

- 仅修改 Flutter 全局主题、首页功能区与健康卡片、个人页头部和服务图标，以及对应视觉回归测试。
- 没有修改健康数据来源、未知值处理、设备能力、戒指测量、登录、商城、推送、在线更新或服务端接口。
- 不复制 LuckRing 的素材、字体或图标，仅继续参考其大卡片、清晰层级和适合年轻用户的信息密度。
- 真机截图保存在忽略的 `build/` 目录，不提交 Git；真实个人资料和健康数值不写入实施记录。

## 完成内容

### 1. 全局主题改为冷色科技基调

- 页面底色由浅灰紫白调整为更干净的冷灰蓝白。
- 新增科技靛蓝、科技青、科技紫及各自浅色容器色，按钮焦点、输入框焦点、加载指示和普通操作统一使用科技蓝。
- 首页背景渐变由粉色系改为冷白、浅蓝和浅青组合。
- 底部导航仍保留 Say Ring 品牌红作为当前选中态，不扩大到普通信息表面。

### 2. 首页去除大面积粉色

- AI 健康管家卡片改为冷白到浅蓝渐变，并使用蓝色边框、标题和阴影；“立即体验”继续保留品牌红，作为页面关键操作。
- 四个功能入口改为蓝、青、靛紫的图标体系，面板使用冷白到浅蓝渐变。
- 心率/心电、血氧、血压/血糖、体温、HRV、压力、睡眠和成分指标统一改为蓝、青、靛紫渐变大卡片，移除粉橙主表面。
- 保留上一轮的大卡片尺寸、圆角、留白、趋势入口和数据展示逻辑。

### 3. 个人页同步科技化

- 个人资料头卡改为冷白蓝渐变、蓝色描边和蓝色编辑按钮。
- 健康记录摘要使用科技紫，服务入口改为蓝青渐变图标。
- 头像与底部“我的”选中态继续使用品牌红，形成少量且明确的品牌识别。

## 失败、修正与边界

- 编辑个人页摘要颜色时曾产生重复的 `color` 命名参数；在运行测试前的源码检查中发现并删除，最终格式化、分析、测试和构建均通过。
- 源码提交 `d1c2689` 已以普通快进方式推送到开发分支和 `main`，两条远端引用均与本地一致，未强推、未覆盖远端历史。
- 推送后触发的 GitHub Actions `mobile-ci` #32（开发分支）和 #33（`main`）均在约 4 秒内失败：`quality` 与两组 Harmony contracts 没有分配 runner、没有执行步骤且没有生成日志，Android/iOS 因前置任务失败被跳过。现有证据只能确认是 Actions 在开始执行代码前被仓库或账号侧门禁阻断，不能据此认定代码测试失败，也不能猜测具体计费原因；本轮不能标记 CI 通过或线上发布完成。
- 补记 Actions 状态后的首次 `git fetch origin --prune` 遇到 GitHub 连接重置并以 128 退出；命令在暂存和提交前停止，未改变本地或远端历史。保留工作区后重试，再继续最终同步。
- Android 构建仍提示 CameraX 与极光插件使用旧 Kotlin Gradle Plugin 应用方式；本轮构建成功，但未来 Flutter 强制 Built-in Kotlin 前仍需升级对应插件。
- Windows 无法执行 iOS 构建；本轮没有重新构建 HarmonyOS 原生工程。Flutter 共享页面测试不能替代 iOS/HarmonyOS 真机视觉验收。
