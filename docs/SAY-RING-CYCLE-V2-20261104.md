## 实施范围与防复发约束

- `cycle_tracking.dart`：日期按日历而非瞬时时间计算；真实起止/感受与预测分别保存。至少4个实际开始日期、3个完整周期且本人确认无漏记，才按最近最多6个完整周期的最短/最长间隔给参考范围。仅记录、历史不全或过期参考不自行补28天、不向未来滚动。
- `cycle_tracking_service.dart` / `local_health_store.dart`：独立账号周期表，加密库v6→v7仅新增；离线修订、云端版本冲突、删除标记、删除代次、内容寻址快照、迟到账号回调防护。普通健康记录、设备绑定及戒指设置不删除、不下发设置。
- 原生/上传来源：保留原ID/数值/时间；附加可选设备来源、型号、固件、算法、质量和真实睡眠区间。旧数据未知字段不拿当前戒指补填；没有真实睡眠窗口不能用总时长倒推出采样时段。
- 夜间趋势：同一来源/固件/算法分组；皮温语义必须明确，HRV的SDNN/RMSSD分开。保守工程筛选为真实睡眠窗口≥4h、至少4样本、预期覆盖≥70%、最大缺口≤60min；不是医学阈值。没有确认接触状态的结果仅供描述，不能进入增强预测。
- AI：新专属已审说明、独立同意和供应商配置均满足才请求；模型仅选择审核过的动作枚举，日期/数字由代码输出。拒绝或失败时保留固定说明。没有发布说明/配置时不复用睡眠授权、不外发摘要。
- 通知：独立普通日程，锁屏使用泛化文案。默认提前2天9点，用户主动开启；每手机独立通知许可。修改/删除/关闭/换号取消旧计划，Android重启和时区变化重建；不调用健康异常红屏、报警音或戒指振动。
- `tool/cycle_shadow_evaluation.py`：独立研究输入、明确研究同意、参与者分组与时间泄漏检查、L2离散风险候选、提前7/3天对照、按用户bootstrap。始终`released=false`，不读会员库、不训练线上通用模型。真实20–30人连续3周期研究及正式独立验证尚未进行。
