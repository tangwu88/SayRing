## 代码与 SDK 核对

- `Index.ets` 设备按钮使用 `!wearableBusy() && !wearableMeasurement.running`；断开入口只检查连接任务是否忙。测量中禁用其他 SDK 指令是现有安全互斥，不应删除。
- 心率页的 `trend_measure` 使用当前指标与真实 `running` 状态决定“手动测量 / 结束测量”；查看另一指标的“手动测量”文案，不能据此判断没有任何测量占用。
- `VepWearableService` 的心率分支订阅实时推送并显式启动；`onHeartRate` 更新有效值或佩戴提示，不自行生成心电式完成事件。停止通过官方 `heartRateService.stopMeasurement()`，随后清理当前测量状态与命令占用。
- 官方 [API 速查](https://github.com/HBandSDK/HarmonyOS_BLE_SDK/blob/main/docs/API.md)及锁定 HAR 声明均包含心率 start、stop、push 接口。当前 App 按持续测量使用与该接口形态一致，但文档未证明具体固件一定多久自动结束，不能宣称已验证厂商自动结束期限。
- 保留日志没有提供该次心率的完整开始链路；既不能确定谁发起，也不能将未找到起始行解释为 SDK 未启动。
