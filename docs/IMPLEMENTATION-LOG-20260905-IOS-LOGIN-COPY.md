## 防回归要点

1. 微信授权与支付使用不同通道；授权响应不写支付结果缓存，支付响应不完成登录。
2. 仅接受当前请求的 state；重复点击、取消、超时、其他请求与迟到回调不得写会话。code 换会话之前不进入首页，服务端未返回稳定账号 ID 时拒绝登录。
3. 微信 AppSecret 不进入客户端、截图或日志；配置缺失只给用户短提示，详细阻断在开发记录保留。
4. 精简文案不删除同意协议、健康安全提醒、权限处理、空态与重试。首页迷你图空态不再重复徽标的“暂无数据”，读取失败仍单独显示。
5. 共用 Flutter 页面修改会影响 Android 文案，微信登录入口仅 iOS；不修改现有鸿蒙文件和蓝牙协议。

## 微信登录联调前必须补齐

- 微信开放平台登记的 iOS Bundle ID、Universal Link，以及相匹配的 AppID；注入现有本地/CI 配置，不猜测生产值。
- Universal Link 域名验证和具备 Associated Domains 能力的合法签名；当前个人团队 QA 包不满足正式链路验收。
- 确认 iOS `code/state/group=app/platform=ios` 的服务端换会话契约，并返回有效 token 与稳定 member ID。空参数探测返回业务 404 只说明该次请求未成功，不代替真实授权联调。
- 使用真实授权检查允许、拒绝、取消、重复点击、超时、微信回跳与登录后的账号数据隔离。当前自动化测试通过不等于微信开放平台和服务端已可用。
