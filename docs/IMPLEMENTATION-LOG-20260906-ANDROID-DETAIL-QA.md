## 发现与修复

| 级别 | 发现 | 处理与防复发 |
| --- | --- | --- |
| P0 | Android 12+ 运行中撤销“附近设备”权限时，打开系统蓝牙可存在权限竞态闪退 | 在发起系统蓝牙请求前二次校验 `BLUETOOTH_CONNECT`，并显式处理 `SecurityException`；读蓝牙开关状态也增加同等保护。 |
| P0 | Veepoo/Yucheng 依赖合并后开启明文网络、允许备份，并将三个内部组件对外暴露 | 强制 HTTPS，关闭云备份和设备迁移，将 DFU、MQTT 和扫描广播组件设为不对外。 |
| P1 | 厂商/插件合并了本 App 不使用的广播、麦克风、旧存储和全应用查询权限 | 在宿主 manifest 显式移除，并在最终 APK 中反查确认不存在。 |
| P1 | 相机插件把摄像头硬件标记为必需，可能阻止部分设备安装 | 相机、自动对焦和 `camera.any` 均明确为可选；头像拍照仍可在有摄像头的手机上使用。 |
| P1 | 上述安全要求只靠手工记忆，SDK 升级后容易回归 | 发行门禁新增最终 manifest 强制验证，危险权限、明文网络、备份、相机限制或组件暴露任一回归都会阻断发行。 |

## 支付、推送与更新细查

- 支付参数仅接收服务端签名结果，客户端不生成签名；微信/支付宝返回后页面会重新读取服务器订单，不把本地回调当成最终到账依据。
- 连续点击已由页面忙状态阻断；取消、未完成、参数缺失和服务端错误都不显示伪成功。
- 本机未注入正式极光 AppKey/厂商通道、生产 API/更新清单和 Android 正式签名；调试包依旧是禁用正式推送的 Debug 签名包，不能用于上线或真实支付验收。
