## 5. Windows 首次运行

建议把 `01-项目源码` 复制到短英文路径，例如 `D:\work\saidian-app`。需要 Flutter
3.44.9、Dart 3.12.2、JDK 17 和 Android SDK。当前机器可直接使用交接包
`06-本地调试入口` 中的 PowerShell 脚本。

```powershell
Set-Location 'D:\work\saidian-app'
Copy-Item config\dev.json.example config\dev.json
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
flutter devices
flutter run -d <Android设备序列号> --debug --dart-define-from-file=config/dev.json
```

天气调试还需使用获授权的 QWeather Key：

```powershell
flutter run -d <Android设备序列号> --debug `
  --dart-define-from-file=config/dev.json `
  --dart-define=QWEATHER_API_KEY=<授权Key>
```

Key 可从交接包 `02-参考资料/Saidian h5和小程序前端源码.zip` 的天气页面实现中，由授权
同事取用。不得把 Key、用户 Token、密码、keystore 或签名密码提交 Git。

## 6. Android 真机调试顺序

1. 手机开启开发者选项、USB 调试、蓝牙和必要权限。
2. 手表靠近手机；若已被别的 App 占用，先让原 App 断开。
3. 执行 `adb devices -l`，确认状态为 `device`。
4. 在 App 中“设备 → 开始查找”，必须使用本轮 HBand 扫描返回的设备地址连接。
5. 手表弹出确认时在 12 秒内确认。
6. 验证“已连接”、固件号、同步数据，然后逐项进入设备功能。
7. 一次只执行一个耗时手表指令；不要绕过 Flutter 串行队列。

日志建议：

```powershell
adb logcat -c
adb logcat -v time | Select-String 'SaidianVeepoo|vepo-bluetooth|FATAL EXCEPTION|ANR'
```
