## 改动

| 复现路径 | 修复 |
| --- | --- |
| 两次取最新的血压历史都明确为空 | 按原厂 EB1 1.0.12 规范，用显式时间上界再做一次反向读取。UTC 和本地钟的上界只决定查询范围，不决定样本时间；超时、拒绝、畸形回包不重发。仅普通历史同步使用这个备用读法。 |
| 连接能力探测后，首次全量同步前新增一条记录，且未收到实时通知 | 把一次真实的血压探测用作观察起点；已有样本不能作为新样本。只在同一连接中接受时间有唯一解释且能核实的新增记录。 |
| 普通历史读到了真实血压，但本机没保存或没回执 | 普通导入与迟到补读共用回执机制。保存前保留同一记录 ID、原时间、血压和脉搏；只在当前连接收到匹配回执才释放。 |
| 一个可选指标超时，中止整个读取或使其他有效记录丢失 | 识别可继续的单项失败，保留已有的有效数据并按现有范围入库、上传；掉线、换设备或账号仍终止本轮。 |
| 手表血压没读到或记录时间未经核实，但 App 提示「数据同步完成」 | 区分未读取、读取失败、明确为空、时间无法确认、待补读和已确认。设备页按本轮血压结果提示，不用活动成功替代血压；戒指的入口和提示沿用原流程。 |
