# 2026-09-28 Say Ring 全局科技色调、设备页与个人中心统一

## 修改原因

上一轮虽然已从粉色转为冷色科技方向，但全局仍残留品牌大红色，设备页、个人中心及部分二级页面的卡片、边框和操作态也没有完全统一。本轮按产品反馈将普通界面全部收拢到蓝、青、靛、紫体系；红色只保留给删除、错误、停止运动和未读提醒等明确危险或告警语义。

## 修改范围与设计边界

- 修改 Flutter 全局主题、设备页、个人中心、运动/心电/关爱/通知/订单等二级页面，以及商城和更新页面中仍然偏暖的直接颜色。
- 设备页重做连接卡、未连接空状态、功能分组标题和功能卡层级；个人中心重做资料头卡、数据摘要、订单、快捷功能和服务区排版。
- 个人中心服务入口由一排 5 个调整为 4 个，窄屏或大字体为 3 个，提高图标和文字可读性。
- 普通按钮、选中态、导航、开关、标签、弹窗和底部面板统一使用科技蓝及冷色描边；高风险心电结果、登录错误、注销账号和运动停止仍使用语义红色。
- 青色正文使用深青色版本，避免浅青文字在白底上的对比不足。
- 没有修改健康数据、未知值、戒指能力、测量、登录、商城业务、推送、在线更新或服务端接口。

## 页面检查

- 全局主题：主色、导航选中态、卡片边框、按钮、开关、标签、弹窗和底部面板均统一为冷白、蓝、青、靛、紫；旧的红/金界面别名映射到新科技色，防止遗漏页面继续出现大面积红色。
- 设备页：连接态采用蓝靛渐变设备图标、冷白蓝渐变主卡和统一操作按钮；未连接态改为蓝青设备图形；个性化与设备功能增加统一分组标题，功能卡使用冷色描边和渐变表面。

- 二级页面：运动、心电、关爱、通知详情、订单详情、商城分类/详情/支付状态、AI 页面及更新页面移除普通场景的大红和暖灰背景。
