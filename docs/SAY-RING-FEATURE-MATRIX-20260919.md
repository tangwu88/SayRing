# Say Ring 功能清单与当前落地状态（2026-09-19）

本清单结合用户此前确定的独立戒指 App、`tangwu88` 国际版后台/H5 会员及健康数据互通、微信首次绑定手机号，以及 2026-09-19 手机上 LuckRing 的首页、睡眠、运动、我的四页观察整理。LuckRing 只作为信息层级与视觉节奏参考，不复制其图片、图标或源码。交接 ZIP 中的描述是待核事实，不自动成为新增需求。

| --- | --- | --- |

## 页面结构

四个底栏为「健康 / 睡眠 / 运动 / 我的」。设备管理从首页概览和“我的”进入；旧设备页与设置/商城详情继续保留，避免视觉调整删掉既有功能。主界面使用原创的深色石墨底、蓝色健康概览卡和绿色状态强调；健康数据与连接状态来自控制器，不用演示数值。

## 上线前不可省略

1. 微信开放平台必须创建/核对 **移动应用** AppID，分别核对 Android 包名 `cn.saydian.ring`、正式签名指纹、iOS Bundle ID/Universal Link；已绑定公众号不等于移动应用授权可用。AppSecret 只存后台，不进 App/仓库。
2. 国际版服务端新增并审核 App 微信授权、首次手机号验证码绑定、票据过期/重放/冲突、会员 UUID 与 H5 同源契约；能力未开放时 App 保持不可用。使用授权测试号分别验首次绑定、复登、换号、冲突和撤销。
3. HR01 的实际 SDK、授权、协议字段、Android/iOS 两端握手及历史包确认后再接入；验证三轮连接/同步/断开/重连，不干扰 LuckRing 已有绑定。
4. 用授权测试会员验证 H5↔App 的资料、健康记录与时区/重复数据，核对线上版本、CI 与正式签名后才能发布。当前 APK/源码均不是生产验收结论。
