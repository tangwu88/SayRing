# 健康首页睡眠入口与提醒入口调整

2026-11-05。基线为开发分支 `codex/integrate-latest-20261031` 的 `92d406d`。工作树干净时已核对远端并检查交接、复盘与回归清单。本轮本机验证使用普通 Say Ring 1.0.11（1254）。

## 复现与修复

- XR 旧版 1247 与实际 R7 Ultra 完成 SDK 握手后，健康首页仍没有「睡眠概览」。当前连接回传的指标和历史指标清单中均无睡眠。R7 Pro 的产品资料列有睡眠监测。原厂 iOS 说明中，一段睡眠数据只推送一次，功能表没有独立的睡眠开关。iOS 适配器以有效睡眠批次或结束回包登记睡眠指标，首页过去直接复用这个条件。Android 原有适配在完成握手后登记睡眠指标。
- `lib/services/app_controller.dart` 将打开睡眠概览与采集能力分开。原有睡眠能力已获确认时沿用原入口。额外的只读入口要求当前戒指握手就绪、正式版本允许睡眠、已确认历史通道，并匹配正确通道的 R7Pro、HR05 或 R7Ultra 原生型号。仅缓存绑定、同名设备或其他型号均不能触发这条例外。
- `lib/ui/pages/dashboard.dart` 使用独立的睡眠入口条件，同时移除首页的「健康提醒」卡片和配套间距。「设备」保留按设备能力开放的入口，「我的」保留通用入口。`lib/ui/sleep_detail_widgets.dart` 区分通道支持历史与当前已确认睡眠历史，空白日可以直接查看其他日期。
- 浏览仍按当前账号与戒指读取既有睡眠记录。此次不补造睡眠、不触发测量、设置下发或初始化，不修改同步、加密库、通知或健康提醒规则。
