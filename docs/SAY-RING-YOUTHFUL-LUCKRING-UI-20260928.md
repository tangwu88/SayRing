# 2026-09-28 Say Ring 年轻化界面与首页健康大卡片

## 修改原因

按产品要求，以手机中已安装的 LuckRing 为页面层级参考，进一步把 Say Ring 调整为更适合年轻戒指用户的视觉风格。重点不是复制 LuckRing 的黑色主题或素材，而是吸收其大卡片、强层级、充足留白和鲜明状态色；Say Ring 继续保留现有红色品牌和浅色主调。

## 参考与设计边界

- 现场查看 LuckRing 的首页、睡眠、运动和个人页，确认其主要视觉语言是整行大卡片、大圆角、简洁标题、突出核心数据和明显的功能分区。
- 未复制 LuckRing 的图片、图标、字体或其他受保护素材；仅参考信息层级和布局节奏。
- 本轮只修改 Flutter 视觉组件与对应页面回归测试，没有修改健康值来源、有效性判断、趋势计算、手动测量、设备能力或服务端接口。
- 真实健康结果只用于现场显示检查，本记录和 Git 不保存具体数值；现场参考截图位于忽略的 `build/` 目录，不提交仓库。

## 完成内容

### 1. 首页健康数据改为整行大卡片

- 原两列小卡片改为单列全宽卡片，每项拥有更充足的标题、状态、数值、单位和趋势空间。
- 心率/心电、血氧、血压/血糖、体温、HRV、压力、睡眠和成分指标分别使用克制的粉橙、蓝紫、橙粉、紫蓝、绿杏等浅色渐变。
- 卡片使用大圆角、轻阴影、半透明状态标签和抽象圆形装饰，增加年轻感但不影响文字对比度。
- 点击卡片仍进入原健康趋势页；支持手动测量的指标继续沿用原测量入口与设备能力门禁。

### 2. 首页功能区统一年轻化

- AI 健康管家卡片统一为 26 像素圆角并增加柔和投影，保留原人物与品牌红色按钮。
- 远程关爱、健康百科、运动和商城入口使用白到浅粉的独立面板、彩色渐变图标和轻投影。
- 页面背景调整为更温和的浅灰紫白，继续保留 Say Ring 红色品牌识别。

### 3. 全局表面风格收拢

- 通用卡片圆角由 22 调整为 26，降低默认硬阴影，由各场景使用更柔和的层次表达。
- 输入框圆角由 12 调整为 18，使登录、资料和设置类页面与首页视觉保持一致。
- 未改变底部三栏结构、页面路由、按钮业务行为和任何接口参数。
