# 三端五层页面检查矩阵

本矩阵以当前 iOS/Android 共用 Flutter 生产页面为基准，鸿蒙按页面职责对应。**源码存在、自动化通过、真机通过为三个不同状态**。下表默认均需本轮三端实机补齐，未填写证据的项目不能计为通过。

层级定义：健康/设备/我的首页为第 1 层；进入内页加一层；页面内规格、选择器、编辑与确认弹窗作为下一层子节点；相同内页不同入口分别检查返回与状态。第 5 层页面的操作结果、返回、空态仍需验收，不能因到达第五层就跳过按钮。

## 每页统一验收

- 相同页面状态、同尺寸比较：标题、返回、字号、留白、真实图片、卡片、主操作和底部安全区；截图文件标明平台/版本/页面/状态。
- 320/360/390/430 宽与 600/840 宽；系统字号 100/130/150/200%；横竖变化后不溢出、不裁切，重要操作至少48vp，大字主要卡片与编辑区域单列。
- 加载、空、错误、未登录、无权限、设备不支持、有真实数据分别验；没有真实数据只记未覆盖。
- 输入法显示/收起、滚动到底、按钮连点、返回后再进、从另一入口进入、应用前后台/冷启动需保留正确状态。
- 本人手表历史、App手测、远程成员各自保留数据来源；跨账号不可串数据。
