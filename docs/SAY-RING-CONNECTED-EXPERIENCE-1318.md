# Say Ring 1318 四项功能内测候选

## 基线和使用范围

- 从 `aa15efededcfcbbe00d4bcf7b19c5a4cb21a618e` 开发，版本 1.0.15（1318），分支 `codex/say-ring-connected-experience-20261123`。
- 后台对应分支位于 `tangwu88/saydianserver`，已核对远端提交 `75f00a064d224af76e6152d4b147dc5b385938a7` 的代码树。包含第一方 H5、远程爱、运营后台、固件清单和分项开关。客户端优先读取后台公布的能力，兼容仍未部署接口的旧服务。
- iOS、Android 复用正常入口和现有健康记录来源。发行审核版本保持原状态。

## 功能

- 健康页心血管趋势区分本人录入的上臂参考值与穿戴来源，提供 7 天、30 天、来源记录和同期指标。单日序列只画数据点，缺失日期断开。跨期比较要求同一来源的两段各有至少三个有效记录日。参考值和依据按账号范围加密保存在本机，观察由本机样本和随包通用文案生成。U19 须有实际型号和固件资格，并核对本机及云端测量时间和双值。
- 日睡眠报告、健康记录和运动记录可以预览所选快照再分享。我的这一周从真实记录生成私人卡片，并可补充一句话后自愿分享。我的分享支持管理与查看回应。
- 远程爱支持 48 小时一次性链接或邀请码、登录后继续、受邀者选择共享指标、亲友问候和近况、每周散步约定以及最长 10 秒语音。收件箱可跳回关系详情。两端有对应的系统关联配置。
- 固件入口验证后台签名清单、SHA-256 和设备身份。iOS QRing 的原厂传输路径等待同一设备回读目标版本后才成功。分发和本机入口都受能力限制。戒指轻振为收件人选择开启，前台待命时仍须命中通过双端实测的型号和固件名单。

## 已执行与问题修正

- 起初完整测试发现新入口触及老测试中的非 Say Ring 产品替身。调整能力判断顺序并补实测试对象的产品类型，定向回归通过。后续完整检查覆盖原戒指、运动、健康、睡眠和通知路由。
- 320 px 宽、两倍文字的中英文试录发现，本机保存完成后，调试模式的页面刷新回调错误返回了异步结果。修复趋势刷新、分享列表撤回和邀请重载，再确认收缩压、舒张压从两个空字段录入且单条读数各画一个点。
- 首次 iOS 构建耗在仓库递归清理可选扩展属性。限制该清理进程后改用 Xcode 串行构建。首次原生编译还发现电量回调选择子拼写差异，已按原厂头文件修正。Android 发布门禁改为仅在使用录音或声明麦克风时要求该硬件为可选，兼容旧客户端。
- iPhone XR 从 1316 到 1318 使用同一 Bundle ID 原位覆盖，已核对 App 安装版本与启动。覆盖前后逐项健康记录及设置比对、真机新功能流程仍待验。Android 1318 QA 已在独立 ARM64 模拟器安装、冷启动，英文两倍字号的登录页可滚动到无需登录的预览入口。华为现有包签名与 QA 包不同，保留已安装应用及数据。
