相关测试与实机入口将验证无绑定时只列手动候选、不得自动选择；本次旧 R21 日志只允许一次作为同账号已验证手动候选迁入，不导入健康值或恢复手机备份，不重置戒指。

## 存储边界

独立历史 key 以环境和账号哈希隔离，最多四个目标；绑定 key 不再包含 recentBindings。旧 v2 已验证当前/历史在新握手或解绑前迁移；无 owner 的旧记录不迁移到任意账号。历史损坏不静默覆盖。绑定/历史补偿回退在同一路由实例的串行写入队列中执行；不是跨进程数据库事务，持久存储本身持续不可用时不能保证回退成功，不将这种情况当作保存成功。

## 实物入口

新增 integration_test/ios_qring_cached_connection_test.dart，只使用真实生产 API、账号和 QRing SDK；目标 UUID/名称及预期账号哈希通过 Git 外定义文件传入。首次只在当前账号健康记录证实同一旧目标、历史 key 尚不存在时，一次性迁入用户授权的旧握手日志候选；不写健康值或绑定。SDK 清空命令由 QA guard 拦截，若尝试非零立即判失败。

连接通过正常 AppController；检查精确缓存候选、真实能力就绪/固件、解绑后四秒不自动重绑、候选持久化和再次明确连接，以及主动重连。该受控重连不替代自然远离/靠近三轮。验收结束必须覆盖回普通 main，不把测试入口留作日常 App。

旧 Debug 1207 VM 已不可达，本轮 USB 仍识别目标手机；预期账号哈希来自本次先前手机界面证据，新测试初始化必须重新比对，否则在任何历史迁入前失败。

## 首次实物验收 1208 未执行连接

## 1209 真实连接验收及普通主入口

修正私有预期账号后，1209 QA Profile 构建 39.6 秒、62.0 MB；普通 main Profile 串行构建 46.4 秒、61.8 MB，两份分别冻结、验签并核对符号，不将测试入口当普通主入口。测试包配置包含私有目标定义，普通 main 仅生产 API 定义，不包含目标导入逻辑或 NoClear guard。

第一次 1209 Flutter 启动出现 HttpException / WebSocket 连接头提前关闭；测试尚未开始。旧 usbmux 列表当时缺少目标，但重新插接后 ioreg 与 CoreDevice 已确认同一手机物理接入、有线隧道连接。停止了未确认旧通道的后续尝试，改用 devicectl 原生安装/启动和当前 CoreDevice IPv6 隧道。通过精确 PID、签名安装构件及受认证 VM 验证对象，再由保留应用包装工具 --use-existing-app 执行；不卸载、不改包名、不替换账号或清数据。

实物 1209 QA 整轮通过、驱动退出 0：当前账号持有同一原 R21 记录，一次迁入仅供明确选择的历史候选；首次真实缓存连接 1100 毫秒，解绑后四秒未连接且未自动重绑，历史仍可查；再次选择保留候选连接 792 毫秒；主动重连回到同一目标并取得新的能力对象。三处都通过真实 SDK 与正常 AppController；固件 RF22B_2.00.12_261028，NoClear 的清空调用次数断言始终为 0。

这些是同一 iPhone 15 Pro Max / R21_C280 当前条件下的受控样本，不能与此前 XR/R8 的 3369 毫秒直接作性能优劣比较，也不能替代自然距离重连。

测试结束通过 devicectl 原位覆盖回已冻结普通 lib/main.dart Profile 1.0.8（1209），仅 iPhone、原 cn.saydian.ring / W7SXQ4A226。新普通进程 1526 已自动恢复同一 UUID，账号哈希匹配、固件实读、能力 ready、无测量中；没有点击重连或调用测试连接方法。本次手机本地备份/恢复均未执行，现有 App Store 审核及服务器配置未变更。

原生开发隧道在安装/重启后地址变化，首次普通主入口观察使用旧地址超时；更新当前地址并保留只读原生日志观察连接后，VM 恢复可达，普通 App 一直在运行。不可将隧道地址失效等同于 App/戒指崩溃。当前只读采样仅检查连接、目标、账号及能力元数据，测量/睡眠/AI等均未触发专项测试。
