# Say Ring 1330 英文界面与 XR 复测

2026-11-26，基于 App 提交 `a7826a6`。复查中国版 Say Ring 跟随英文系统时的界面、连接提示和同步反馈。

## 问题与修复

在英文环境中让 U19 历史读取失败，1329 的同步提示回退为中文，自动回归也复现此问题。网络错误清理后曾回到固定中文提示，影响登录绑定、设备同步及其他调用同类提示的页面。两项问题影响操作提示的可读性。

- 在界面显示处按当前语言翻译已知错误和状态。补齐设备发现、重连、同步失败或部分完成、测量、登录和常见服务提示。连接状态里组合的原因也使用英文，数字保留原值。
- 戒指连接提示使用 ring，手表使用 watch 或 device。同步等待的无障碍朗读采用对应语言的标点。
- 英文常见问题页标题改为 FAQ，避免 XR 上长标题被截断。中文原文标为 Chinese，文章和用户内容照原文显示。

## 验证记录

- 用 `flutter test --no-pub test/ui_shell_test.dart --plain-name 'U19 history read failure follows the English UI locale'` 复现失败。修正后，登录、U19 页面、设备提示、分享、FAQ 和主界面的 341 项定向回归通过。针对英文界面会显示中文的重新搜索提示，补充可复现断言。
- U19 窄屏双倍字号用例覆盖设备设置、健康监测、亮屏时长、脉搏指数和查找手表。打开校时选项的用例确认没有设置写入。英语、简体中文和其他系统语言回退均纳入测试。
- XR 在 1329 上显示英文设备首页，连接 U19M 并实际运行普通同步。界面观察到同步进度结束。此次没有观察到新血压记录。
- 换 Wi-Fi 后，XR 的原生 HTTPS 探测仍返回 `NSURLErrorDomain -1009`，系统报告 Wi-Fi 请求被拒绝。保留 App 数据，用签名 Profile 及 `tool/drive_ios_preserving_data.mjs` 复查，确认 Say Ring 进程实际访问中国站出现 `SocketException`，读取授权未取得。缓存候选需要重新发现，诊断运行未完成手表连接。无血压历史读取指令、回包或云端读回。本轮未执行校时或启动新测量。
- XR 退出临时诊断后原位恢复正常 1329 并确认启动。后续开发签名 1.0.15（1330）覆盖安装，系统读回包名和版本。
- 1330 首次真机界面检查通过健康、设备、我的与常见问题导航。校时用例先因延用了上一条用例的 FAQ 页面未找到设备标签。冷启后发现用例把已显示但禁用的同步按钮当作连接成功，XR 截图实际显示英文等待重连。调整为要求连接标记和设备电量同时出现，通过正常搜索仍未确认该表在线，校时界面真机用例记为跳过。
- Android 模拟器首次 1330 启动只确认了进程一度存在，随后回到系统桌面。复查时 1329 在系统重建 Activity 的清理阶段触发第三方蓝牙库的空指针异常。之后安装 1330，App 保持前台并显示英文登录页。原始异常与同步日志按轮次保存。
